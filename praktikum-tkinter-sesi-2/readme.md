# Praktikum Tkinter Sesi 11

## Aplikasi Pendaftaran Kegiatan Mahasiswa

1. Deskripsi
   Aplikasi Pendaftaran Kegiatan Mahasiswa merupakan aplikasi GUI sederhana yang dibuat menggunakan Python Tkinter. Aplikasi ini digunakan untuk mengisi data mahasiswa, memilih program studi, menentukan jenis kelamin, memilih kegiatan mahasiswa, serta menampilkan ringkasan hasil pendaftaran.

2. Tujuan
   Menerapkan penggunaan berbagai widget Tkinter, event handling, validasi input, menu, dan dialog dalam pembuatan aplikasi GUI.

3. Fitur Aplikasi

- **Entry:** Memasukkan nama mahasiswa.
- **Combobox:** Memilih program studi (Sistem Informasi, Teknologi Informasi, dan Teknik Informatika).
- **Radiobutton:** Memilih jenis kelamin.
- **Checkbutton:** Memilih satu atau lebih kegiatan mahasiswa.
- **Text:** Memasukkan alasan mengikuti kegiatan.
- **Listbox:** Menampilkan daftar kegiatan yang dipilih.
- **Submit:** Menyimpan dan menampilkan ringkasan pendaftaran.
- **Reset:** Mengosongkan seluruh formulir.
- **Messagebox:** Menampilkan notifikasi dan peringatan.
- **Menu File:** Menyediakan pilihan Keluar.
- **Menu Bantuan:** Membuka jendela About.
- **Toplevel:** Menampilkan informasi tentang aplikasi.
- **Validasi Input:** Memastikan nama tidak boleh kosong dan pilihan wajib sudah diisi.
- **Event Keyboard:** Tombol Enter digunakan untuk menjalankan Submit.

4. Teknologi yang Digunakan

- Python
- Tkinter
- Tkinter TTK
- Messagebox

5. Cara Menjalankan Aplikasi

1. Pastikan Python sudah terinstal di komputer.
1. Download atau clone repository ini.
1. Buka folder proyek menggunakan Visual Studio Code.
1. Buka terminal pada folder proyek.
1. Jalankan perintah berikut:

```bash
python pendaftaran_kegiatan_mahasiswa_lengkap.py
```

6. Output Aplikasi
   Aplikasi menampilkan formulir pendaftaran mahasiswa dan ringkasan data setelah tombol Submit ditekan.

7. Kesimpulan
   Melalui praktikum ini, penggunaan widget Tkinter, pengelolaan event, validasi input, menu, dan dialog dapat diterapkan dalam pembuatan aplikasi pendaftaran kegiatan mahasiswa.
